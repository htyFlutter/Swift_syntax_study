Closures

名前のない使い捨て関数
からね クロージャ＝名前つけてない、その場で使い捨てる関数のこと。Pythonの lambda と一緒。マジむずくない。
🍩 たとえ話でいくよ
  • 普通の関数 = レシピ本📖に載ってる料理。名前があって何回も作れる。
  • クロージャ = その場で「これやって」ってメモ📝。名前いらん、一回きりの使い捨て。

キーポイント

  • { n in n * 2 } = 「n もらって2倍して」ってメモ。区切りは in。
  • map = 全員に同じ処理かける / filter = 条件に合うやつだけ残す。
  • reduce = 全部を1個に煮詰める（合計とか）。
  • $0 = 「1個目の引数」の超省略形。{ $0 * 2 } でOK。

Python / Dart → Swift

元Swift
Python lambda n: n*2→{ n in n * 2 }
map(f, xs)→xs.map { }（リストが前）
filter→filter（ほぼ同じ）

コード例

let nums = [1, 2, 3, 4, 5] nums.map { $0 * 2 } // [2,4,6,8,10] 全員2倍 nums.filter { $0 % 2 == 0 } // [2,4] 偶数だけ残す nums.reduce(0) { $0 + $1 } // 15 全部を1個に煮詰める
⚠ 罠  filter は条件がtrue のやつだけ残る。%（余り）と *（かけ算）を打ち間違えると、条件が全部 false になって全部消えるから気をつけな。
