Strings & Characters

文字列・文字
☕ この章はざっと流した回。DartとほぼいっしょだからサラッとでOK。違うとこだけ押さえとけば十分よ。

キーポイント

  • 文字列補間は \( )。Dartの $ とここだけ違う。
  • 文字数は .count（.length じゃない）。
  • 複数行は """ で囲む。
  • 連結は + でそのままOK。

Dart → Swift 変換

DartSwift
"$name"→"\(name)"
str.length→str.count
'''…'''→"""…"""

コード例

let name = "はやと" let msg = "こんにちは、\(name)さん" // 補間は \( ) print(msg.count) // 文字数 let many = """ 1行目 2行目 """ // 複数行文字列
⚠ 罠  "$name" はDartの癖。Swiftは "\(name)"。最初みんなここで間違えるから、指に覚えさせなさい。
