Control Flow

分岐・ループ・switch・guard
からね Swiftの switch は Dart とは別次元。範囲・where・タプル、三種の神器を使いこなしなさい。

キーポイント

  • for-in / while はほぼ同じ。if のカッコは不要、{} は必須。
  • switch: break不要・複数case・範囲 1...25・where 条件つき。
  • switch はタプルもマッチできる（座標判定など）。
  • guard = ダメなら早期リターン。ネストが減って読みやすい。

Dart → Swift 変換

DartSwift
if (x)→if x（カッコ不要）
case 1: … break;→break 不要で勝手に止まる
if(x==null) return;→guard let x else { return }

コード例

switch num { case 1...25: print("序盤") // 範囲でまとめる case let n where n % 10 == 0: print("キリ番") // 条件つき default: print(num) } func greet(_ name: String?) { guard let name else { return } // 空なら即帰る print("やあ \(name)") // 以降ずっと String }
⚠ 罠  guard の else は必ず抜ける処理（return等）が要る。switch は全パターン網羅しないとエラーになる ── 書き漏れをコンパイラが許さないの。
からね: ダメなパターンを先に弾く。残ったら正常処理。それが guard の美学よ。
