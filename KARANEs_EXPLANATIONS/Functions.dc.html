Functions

引数ラベル・戻り値・タプル返し
からね 引数ラベルは Dart に無いSwiftの主役。コードが英文みたいに読めるようになるのよ。

キーポイント

  • func 名前(引数: 型) -> 戻り値。戻り値は後ろ（->）。返さないなら省略。
  • 引数ラベル: 呼ぶ時に名前を書く。to / from で英文っぽく。
  • _ を付けるとラベルを省略して呼べる。
  • タプルで複数の値をまとめて返せる（Dartなら class が要る場面）。

Dart → Swift 変換

DartSwift
int add(int a)→func add(a: Int) -> Int
add(3, 5)→add(a: 3, b: 5)
（位置引数）→func f(_ x: Int) → f(5)

コード例

func greet(to name: String) -> String { return "やあ、\(name)さん" // 呼ぶ時 greet(to:) } func minMax(_ xs: [Int]) -> (min: Int, max: Int) { var lo = xs[0]; var hi = xs[0] for n in xs { if n < lo { lo = n }; if n > hi { hi = n } } return (lo, hi) // タプルで2値返す } let r = minMax([3, 9, 1]) print(r.min, r.max) // 1 9
⚠ 罠  ラベルを書かずに greet("はやと") と呼ぶとエラー。省略したいなら定義側に _ を付ける。print するだけが関数じゃない ── 値を返す箱だと意識しなさい。
