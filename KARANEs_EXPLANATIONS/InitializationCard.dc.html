Initialization

初期化 / init・デフォルト値・init?
からね 初期化＝インスタンスを作る瞬間の「儀式」。全プロパティを埋めろ、ってSwiftがうるさく言うアレ。Flutterの const Widget({required this.x}) と同じ役目よ。
🍩 たとえ話でいくよ
  • init = インスタンス誕生の儀式🎁。全プロパティを埋めて初めて生まれる。
  • デフォルト値 = 最初から書いといた初期値📝。var hp = 100 なら埋め忘れOK。
  • init? = 変な値なら「生ませない」門番🚪。失敗したら nil を返す。

キーポイント

  • プロパティを1個でも埋め忘れたらエラー。self.x = x で埋める。
  • デフォルト値（= 100）があれば init で埋めなくてOK。
  • init は引数の組み合わせが違えば何個でも作れる。
  • init? は return nil で「作成失敗」を返せる → if let で受ける。

Flutter / Dart → Swift

元Swift
const A({required this.x})→init(x:) { self.x = x }
this.x→self.x
名前付きコンストラクタ→複数の init

コード例

struct Player { var name: String var hp: Int init?(name: String, hp: Int) { // 失敗できるinit if hp <= 0 { return nil } // 不正なら生ませない self.name = name self.hp = hp } } if let p = Player(name: "勇者", hp: 100) { print(p.name) }
⚠ 罠  init? が返すのは Player?（Optional）。だから if let か ?? で受けないと中身を使えない。前にやった Optionalの仲間よ ── バラバラに習ったのがここで繋がる。
からね: init?・??・三項 ── ?ファミリーを1画面で連携させたでしょ。「親の顔より見た?」、もう完全にあんたのものよ。
