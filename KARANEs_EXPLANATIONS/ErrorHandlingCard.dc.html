Error Handling

throws・throw・do-try-catch
からね 失敗するかもしれない処理の作法。Javaの try-catch とほぼ同じよ。学校の課題で書いたでしょ？記憶が新鮮なうちに移植しちゃお。
🍩 たとえ話でいくよ
  • throws = 「この仕事、失敗することあるよ」の事前申告📋。
  • throw = 「失敗した！」とボールを投げる⚾。
  • do / try / catch = 投げられた失敗をミットで受け止める🧤。

キーポイント

  • エラーの種類は enum AgeError: Error で定義（Javaの例外クラス）。
  • 失敗しうる関数は func f() throws、中で throw。
  • 呼ぶ側は do { try f() } catch { } で囲む。
  • catch AgeError.tooYoung と書けば種類別に対応を変えられる。

Java → Swift

JavaSwift
throws / throw→throws / throw（同じ）
try { ... } ブロック→do { ... }
（自動）→危険な行ごとに try を付ける

コード例

enum AgeError: Error { case tooYoung } func checkAge(_ age: Int) throws { if age < 18 { throw AgeError.tooYoung } print("入場OK") } do { try checkAge(15) // 失敗→catchへ急行 } catch AgeError.tooYoung { print("まだ早い") }
⚠ 罠  綴り注意 ── throws は th-r-ows（thows はエラー地獄、しかも10個連鎖）。throw された瞬間、その後の行は全部スキップして catch に飛ぶ。Javaと同じ挙動よ。
