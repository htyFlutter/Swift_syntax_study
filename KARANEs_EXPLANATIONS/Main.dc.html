The Basics

変数・型注釈・オプショナル
からね ここが全部の土台よ。特にオプショナルは山場。逃げずに向き合いなさい。

キーポイント

  • let が定数、var が変数。迷ったら let ── 書き換える時だけ var にする。
  • 型注釈は 名前: 型 の順。Dartと逆で型が後ろ。TypeScriptと同じ並び。
  • Optional は「中身が入ってるか分からない箱」。型の後ろに ? が付く。
  • 箱は if let で開ける。空っぽの箱は nil。

Dart → Swift 変換

DartSwift
final x = 1→let x = 1
String? name→var name: String?
"Hi $name"→"Hi \(name)"
if (x != null)→if let x

コード例

let name = "はやと" // 型推論で String var age: Int = 24 // 型注釈は名前の後ろ let nick: String? = nil // ? = 中身が無いかもの箱 if let nick { print(nick) // 箱を開けて中身を使う } else { print("名無し") // 空箱 (nil) だった }
⚠ 罠  ? は「大事だから守る」印じゃない。「空っぽかもしれない」の注意マーク。付けるか迷ったら「これ、空っぽってある?」だけで判断しなさい。
