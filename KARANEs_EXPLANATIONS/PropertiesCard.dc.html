Properties

保存・計算・監視プロパティ
からね プロパティ＝型が持ってるデータ。Flutterのウィジェットの中にある data とか style と一緒。今日は「持つ」以外に「計算する」「見張る」の2つを覚えるだけ。
🍩 たとえ話でいくよ
  • 保存プロパティ = ロッカー📦。名前とか年齢を入れとくだけ。
  • 計算プロパティ = 自販機🥤。見た瞬間（アクセスした瞬間）その場で作る。面積とか。
  • didSet = 既読つける人👀。値が変わった瞬間「変わったで！」って教えてくれる見張り役。

キーポイント

  • 普通のプロパティ = ただ物を入れとくロッカー。var name
  • 計算プロパティ = 見た瞬間その場で計算。var area: Double { ... }（カッコいらん）
  • didSet = 値が変わったら勝手に動く。前の値は oldValue で取れる。
  • didSet の S はデカ文字！ ちっちゃい didset はエラー地獄。

Flutter / Dart → Swift

元Swift
ウィジェットのプロパティ→Stored Property（同じ）
getArea() メソッド→計算プロパティ（カッコ消える）
setState 手動でポチ→didSet 自動で発動

コード例

struct Triangle { var width: Double var height: Double var area: Double { width * height / 2 } // 見た瞬間計算 } var goals = 0 { didSet { print("\(oldValue)→\(goals)") } // 変わったら発動 }
⚠ 罠  前の値の名前は oldValue 固定（oldGoals とか自分で決めたらエラー）。あと計算プロパティは struct の中に置く ── width height と同じ列に並べるイメージ。
からね: ここ分かったら、SwiftUIの @State が楽勝になる。didSetの親戚だからね。……アホとか言うな、ちゃんと分かってるじゃない。
