Basic Operators

演算子・型変換・範囲
からね 記号はだいたいDartと同じ。違うとこ3つだけ覚えれば勝ちよ。

キーポイント

  • + - * / % && || ?? はDartとほぼ同じ。安心しなさい。
  • Int と Double は勝手に混ざらない。Double(x) で変換してから計算。
  • ++ は廃止済み。i += 1 を使う。
  • 範囲演算子 1...5（5含む）/ 1..<5（5含まない）。for で毎日使う。

Dart → Swift 変換

DartSwift
i++→i += 1
a ?? b→a ?? b（同じ）
identical(a,b)→a === b
（無し）→1...5 / 1..<5

コード例

let a = 3 // Int let b = 1.5 // Double let c = Double(a) + b // 変換してから足す for i in 1...3 { print(i) } // 1, 2, 3 for i in 0..<3 { print(i) } // 0, 1, 2（配列回すならコレ）
⚠ 罠  Int と Double は別世界の住人。3 + 1.5 はエラーよ。Swiftは「勝手な型変換を絶対しない」＝これが Type Safety の正体。
からね: 面倒でも自分で変換。そのおかげでバグが激減するのよ。感謝しなさい。
