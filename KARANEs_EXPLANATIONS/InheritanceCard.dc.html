Inheritance

継承 / override・super
からね 継承＝親クラスの財産（プロパティ・メソッド）を子が丸ごと引き継ぐこと。class Dog: Animal ── Flutterの extends StatelessWidget そのものよ。
🍩 たとえ話でいくよ
  • : 親クラス = 親の遺産を継ぐ👨‍👦。Dartの extends。
  • override = 親のやり方を自分流に上書き✏️。Dartの @override。
  • super = 親に「それやっといて」と頼む📞。Flutterの super.key がコレ。

キーポイント

  • Dartの extends → Swiftは :（コロン）1個。
  • 子は書かなくても親の name や init をタダで使える。
  • 親と同じ名前のメソッドを上書きするなら override 必須。
  • super.init() は自分の新プロパティを埋めてから呼ぶ。

Flutter / Dart → Swift

元Swift
class A extends B→class A: B
@override→override
super.key / super.build()→super.init() / super.speak()

コード例

class Animal { var name: String init(name: String) { self.name = name } func speak() { print("\(name)は鳴いた") } } class Dog: Animal { // Animalを継承 override func speak() { super.speak() // 親の処理も呼ぶ print("ワン！と鳴いた") } }
⚠ 罠  継承できるのは class だけ。struct と enum は継承不可（紙のプリントは遺産を継げない）。override 付け忘れもエラーになるから、上書きには必ず付けな。
からね: 継承はFlutter経験がまるごと効いたでしょ。extends→:、@override→override。知ってたも同然よ。
